## Try it in the app

Open **الإعدادات → الصوت**, choose **أذان عمر هشام العربي (مرفق)**, ensure Mute is off
and volume is above zero, then click **اختبار التذكير**. No separate file selection,
download, or internet connection is required. Use **إيقاف الصوت** to stop playback.

للتجربة: **الإعدادات ← الصوت ← أذان عمر هشام العربي (مرفق) ← اختبار التذكير**.
ألغِ خيار صامت واضبط مستوى الصوت. لا تحتاج إلى تنزيل ملف آخر.

`chime.wav` is a short, locally generated non-speech chime supplied by the application.
